# 使用说明

## 启动

先安装 Python 3.10+。macOS 双击 `start.command`，Windows 双击 `start.bat`，Linux 执行 `sh start.sh`。首次运行自动创建 `.venv` 并安装依赖，然后打开控制台 <http://127.0.0.1:8769/>。

## 登录与导出

1. 在“账号与设置”登录原 Replive 账号。手机号发送短信后填写验证码；Google / X 登录会自动准备回调，点击“用系统浏览器打开”授权。
2. 在“导出任务”选择空目录或已有备份目录，点击“开始导出”。
3. 当前任务在各页面顶部显示；可停止任务，已保存的数据保留。
4. 在“备份库”打开页面、更新资源、重新生成页面或校验文件。
5. 以后可直接打开备份目录的 `index.html` 浏览。

生成页面和资源校验使用本地数据，不需要登录。更新资源与补下载依赖在线接口。最近任务显示开始时间、结束时间和耗时，时间按浏览器所在时区显示；“清除”只删除任务记录。备份库的“移除”只取消登记，保留文件，可随时重新添加。

## 回调与会话

Google / X 的回调在登录期间自动接收，完成、取消、十分钟超时、退出登录或关闭服务后自动停止。无法自动接收时使用手动回调，或导入已有 refresh_token。

退出登录删除 `.private/` 中本机保存的会话。关闭服务结束控制台，保留会话和导出文件。请勿公开提交 `.private/` 或导出的私人内容。

## 迁移备份

迁移时复制整个备份目录，再在备份库添加新位置。`_data/` 内保存后续更新和重新生成所需的数据。仅浏览时所需文件见备份目录的 `备份说明.md`。

移动整个项目文件夹时，项目内的默认保存位置和备份库会在下次启动时更新路径；项目外的备份保持原路径。如果文件选择窗口的初始位置已不存在，会从最近的有效父目录打开，仍可转到其他位置。

导出数量、范围和缺失项见 `导出报告.json`、`缺失资源.json`；完整性校验结果见 `校验报告.json`。

完整部署、命令行、使用边界、项目继承与免责声明见 [README.md](../README.md)，来源与许可证状态见 [NOTICE.md](../NOTICE.md)。
